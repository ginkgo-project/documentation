# Community

Ginkgo is built by a community of academic researchers, national-lab
engineers, and external contributors. These pages describe how to get
involved, how the project is governed, and how to cite Ginkgo in your
work.

- [**Contributing**](contributing.md) — Welcome guide for new
  contributors. Ways to help, the quick-start checklist, communication
  channels, and pointers into the detailed how-to guides in the user
  guide.
- [**Governance**](governance.md) — Project structure, decision-making,
  release policy, code of conduct, and funding acknowledgements.
- [**Citing Ginkgo**](citing.md) — The canonical paper, the JOSS
  software citation, and per-feature publications you can cite if your
  work depends on a specific subsystem.
