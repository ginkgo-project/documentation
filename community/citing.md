# Citing Ginkgo

If you use Ginkgo in academic work, please cite the canonical reference:

```bibtex
@article{ginkgo-toms-2022,
  title   = {{Ginkgo: A Modern Linear Operator Algebra Framework for High Performance Computing}},
  author  = {Anzt, Hartwig and Cojean, Terry and Flegar, Goran and G\"{o}bel, Fritz and
             Gr\"{u}tzmacher, Thomas and Nayak, Pratik and Ribizel, Tobias and
             Tsai, Yuhsiang Mike and Quintana-Ort{\'\i}, Enrique S.},
  journal = {ACM Transactions on Mathematical Software},
  volume  = {48},
  number  = {1},
  year    = {2022},
  pages   = {1--33},
  doi     = {10.1145/3480935}
}
```

*Additional citations for specific subsystems (distributed solvers, batched Krylov, mixed-precision preconditioners) and per-release BibTeX entries will be added in the content-authoring follow-up plan.*
