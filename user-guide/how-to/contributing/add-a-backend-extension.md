The `extensions/` tree pattern, modelled on the cuDSS extension: vendor
library discovery in CMake, the opaque-state private member that owns the
vendor handles, the `LinOp` wrapper class, and entry points like
`refactorize` that expose vendor-specific reuse paths beyond the base
`apply` interface.
