# MC64 (matching and scaling)

*This page is a placeholder. Until it is written, the API reference covers the type:*
[`gko::experimental::reorder::Mc64`](https://ginkgo-project.github.io/ginkgo-generated-documentation/doc/develop/classgko_1_1experimental_1_1reorder_1_1Mc64.html)*.*

MC64 finds a row permutation and a pair of diagonal scaling matrices that maximise
the product of absolute values on the diagonal of a sparse matrix. It is most useful
as a numerical-stability preprocessing step before a sparse direct solver, where
having large entries on the diagonal reduces the need for partial pivoting.
