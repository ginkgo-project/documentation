# AMD (Approximate Minimum Degree)

*This page is a placeholder. Until it is written, the API reference covers the type:*
[`gko::experimental::reorder::Amd`](https://ginkgo-project.github.io/ginkgo-generated-documentation/doc/develop/classgko_1_1experimental_1_1reorder_1_1Amd.html)*.*

AMD computes a fill-reducing permutation by greedily picking the row of approximate
minimum degree at each elimination step. It is the recommended default reordering for
sparse direct factorisation on small-to-moderate matrices.
