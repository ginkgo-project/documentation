# `gko::experimental::reorder::Mc64`

MC64 row permutation. Maximises the product (or sum) of absolute
diagonal entries by solving a bipartite matching problem, optionally
returning row and column scalings that bring all diagonal entries to
unit magnitude (with the `max_diagonal_product` strategy). The classical
pre-step for sparse LU factorisations of indefinite / non-symmetric systems.

`generate` returns a `gko::Composition` of two `ScaledPermutation`
operators: the row permutation with its row scaling, and the column
scaling. `Csr::scale_permute` applies both to a matrix.
