# `gko::experimental::reorder::Mc64`

MC64 row permutation. Maximises the product (or sum) of absolute
diagonal entries by solving a bipartite matching problem. With the
`max_diagonal_product` strategy it also computes row and column
scalings that bring all diagonal entries to unit magnitude. The
classical pre-step for sparse LU factorisations of indefinite /
non-symmetric systems.

`generate` returns a `Composition` of two `ScaledPermutation` objects
(row scaling with the row permutation, then column scaling); pass them
to `Csr::scale_permute` to permute and scale a matrix in a single call.
